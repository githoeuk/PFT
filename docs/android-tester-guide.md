# 안드로이드 테스터 설치 및 검증 가이드

## 목적

이 문서는 안드로이드 테스터가 APK를 설치하고, 배포된 백엔드와 실제 비콘 출퇴근 흐름을 검증하기 위한 안내서입니다.

관리자와 아이폰 사용자는 웹으로 접속할 수 있지만, 비콘 스캔 기반 출퇴근은 안드로이드 APK에서 검증합니다.

## 현재 배포 주소

- 관리자/웹 접속: https://githoeuk.github.io/PFT/
- 백엔드 API: 새 백엔드 배포 후 `API_BASE_URL`로 지정
- APK 위치: `D:\demo\PFT\mobile\build\app\outputs\flutter-apk\app-release.apk`

## Play Store 등록 여부

Google Play에 올릴 수는 있습니다. 다만 바로 운영 배포하려면 아래 조건을 고려해야 합니다.

- Play Console 개발자 계정 등록 비용: US$25 일회성 등록비
- Google Play 신규 앱 정식 배포 형식: Android App Bundle(AAB) 권장/필수
- 신규 개인 개발자 계정은 정식 배포 전 폐쇄 테스트 조건이 있을 수 있음
  - 최소 12명 테스터
  - 14일 이상 연속 참여
  - 이후 프로덕션 액세스 신청

따라서 지금 단계에서는 Play Store 정식 등록보다 APK 직접 설치 또는 Play Console 내부 테스트를 먼저 사용하는 것이 현실적입니다.

## 테스트 전 준비

관리자는 웹에서 다음 데이터를 미리 준비합니다.

1. 작업 현장 생성
2. 비콘 등록
   - UUID
   - Major
   - Minor
   - RSSI 기준값
3. 오늘 날짜 작업 일정 생성
4. 직원 계정 생성
5. 테스터에게 직원 아이디와 임시 비밀번호 전달

테스터는 아래 항목을 준비합니다.

- 안드로이드 휴대폰
- 블루투스 켜기
- 위치 서비스 켜기
- 실제 iBeacon 근처에서 테스트

## APK 설치 방법

1. 테스터에게 `app-release.apk` 전달
2. 안드로이드 휴대폰에서 APK 실행
3. "출처를 알 수 없는 앱 설치" 허용
4. 앱 설치 완료 후 실행
5. 권한 요청 시 모두 허용
   - 블루투스
   - 근처 기기
   - 위치

권한을 거부하면 비콘을 찾지 못할 수 있습니다. 이 경우 Android 설정에서 앱 권한을 다시 허용해야 합니다.

## 테스터 검증 절차

1. 앱 실행
2. 직원 계정으로 로그인
3. 직원 홈 화면 진입 확인
4. 비콘 근처로 이동
5. 출근 버튼 클릭
6. 비콘 감지 성공 여부 확인
7. 출근 처리 결과 확인
8. 관리자 웹에서 출석 기록 확인
9. 퇴근 시간 이후 퇴근 버튼 클릭
10. 관리자 웹에서 퇴근 시간 반영 확인

## 관리자 확인 항목

관리자는 웹에서 아래 항목을 확인합니다.

- 직원 계정이 정상 생성되었는지
- 작업 일정이 오늘 날짜로 생성되었는지
- 비콘 UUID, Major, Minor가 실제 비콘과 일치하는지
- 직원 출근 기록이 생성되었는지
- 출석 상태가 정상/지각/조퇴 등으로 판정되는지
- 수기 수정 시 사유와 처리자가 기록되는지

## 자주 발생하는 문제

### 비콘을 찾을 수 없습니다

확인할 내용:

- 휴대폰 블루투스가 켜져 있는지
- 위치 서비스가 켜져 있는지
- 앱 권한이 허용되어 있는지
- 실제 비콘이 켜져 있는지
- 앱에 등록한 UUID, Major, Minor가 실제 비콘 값과 일치하는지
- RSSI 기준값이 너무 엄격하지 않은지

### 로그인이 안 됩니다

확인할 내용:

- 백엔드 API가 정상 동작하는지
- 직원 계정이 활성 상태인지
- 임시 비밀번호를 정확히 입력했는지
- APK가 새 백엔드 API 주소로 빌드되었는지

### 오늘 작업 일정이 없다고 나옵니다

관리자 웹에서 오늘 날짜의 작업 일정을 생성해야 합니다.

작업 일정은 출근/퇴근 판정 기준이 되므로 날짜와 시간이 실제 테스트 시간과 맞아야 합니다.

### 이미 출퇴근 처리된 작업이라고 나옵니다

같은 직원이 같은 일정에 대해 이미 출근 또는 퇴근 처리를 완료한 상태입니다.

반복 테스트가 필요하면 새로운 작업 일정을 만들거나 관리자 수기 수정 기능으로 상태를 확인합니다.

## APK 재빌드 명령어

배포된 API 주소를 사용하는 release APK 빌드:

```bash
cd /d D:\demo\PFT\mobile

flutter build apk --release \
  --dart-define=API_BASE_URL=https://your-pft-backend.example.com/api/v1
```

빌드 결과:

```text
D:\demo\PFT\mobile\build\app\outputs\flutter-apk\app-release.apk
```

## 한계

- 아이폰 웹에서는 iBeacon 스캔 기반 출퇴근을 지원하지 않습니다.
- 안드로이드 웹에서도 비콘 스캔은 안정적으로 지원하지 않습니다.
- 실제 비콘 출퇴근은 안드로이드 APK에서 검증합니다.
- iOS 앱으로 비콘 출퇴근을 지원하려면 Mac과 Xcode 기반 iOS 빌드 환경이 필요합니다.
